# Revisione Markdown

Controlla la gerarchia dei titoli, l'uso delle liste e la leggibilità delle tabelle. Verifica i collegamenti relativi rispetto alla posizione del documento. Per le affermazioni che richiedono una fonte, indica la fonte consultata oppure segnala che manca una verifica.

Riporta i problemi con il titolo della sezione e una correzione concreta. Indica a parte le verifiche che richiedono accesso a un documento o a un servizio indisponibile.
